# Xinge's personal portfolio

[xinge.ca](https://xinge.ca/) · [Projects](https://xinge.ca/projects) · [Résumé](https://xinge.ca/resume)

Built with Next.js, React, TypeScript, and Three.js. Follow the arrows through six 3D voxel chapters, from my arrival in Canada to my first year at Western University, or select **Skip to portfolio** to go straight to the homepage.

## Run locally

```sh
npm install
npm run dev
```

Open [localhost:3000](http://localhost:3000). Run `npm run test:world` to check the journey’s models, content, and movement.
