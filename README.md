# Xinge's personal portfolio

[xinge.ca](https://xinge.ca/) · [Projects](https://xinge.ca/projects) · [Résumé](https://xinge.ca/resume)

Built with Next.js, React, TypeScript, and Three.js. The site opens on my portfolio. Select the Western CS + Ivey line to enter my dorm, then use **Objects** to explore six 3D voxel chapters, from my arrival in Canada to my first year at Western University.

## Run locally

```sh
npm install
npm run dev
```

Open [localhost:3000](http://localhost:3000). Run `npm run test:world` to check the journey’s models, content, and movement.
